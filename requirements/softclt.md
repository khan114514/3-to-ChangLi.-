# SoftCLT：低标注时间序列分类的多阶段表示学习

## 来源与复现入口

- 正式来源：ICLR 2024，*Soft Contrastive Learning for Time Series*。
- [正式论文页](https://proceedings.iclr.cc/paper_files/paper/2024/hash/ccc48eade8845cbc0b44384e8c49889a-Abstract-Conference.html)。
- [官方代码](https://github.com/seunghan96/softclt)，检查版本 `14c638979b129075d7a1111e9f529b9a275ea394`。
- 使用仓内 `softclt_catcc` 半监督分支；数据与预处理见 [TS-TCC](https://github.com/emadeldeen24/TS-TCC)。
- 2026-10-13 在线查重通过；当前多阶段范围困难预评，正式状态待实跑复评。

题目来源是 ICLR 2024 的 SoftCLT。CA-TCC 是实现底座，不以其 TPAMI 来源单独申报顶会选题。

## 建议题目范围

优先 Epilepsy 的 1%／5% 标注预算，必要时预注册 HAR 补充验证。输入为训练时间序列、规定预算内的训练标签和无标签样本，输出为完整编码器/分类器及可重新计算的分类预测。

保留半监督多阶段研究范围：自监督预训练、线性和编码器微调、训练数据伪标签生成、伪标签监督对比再训练及最终分类器。官方 README 提供七阶段流程，阶段文件和依赖均须形成可执行、可恢复的链。

先核对原始样本、分组及预处理的来源。存在可用主体/原始记录 ID 时按分组处理切分；不可用时披露局限，不能宣称已验证分组无泄漏。标注子集、训练/Dev/私有切分固定，两边共用。

## 必需训练与方法接口

每个正式 seed 从初始化独立运行完整声明阶段，记录各阶段实际 epoch、step、训练样本与 checkpoint。上游权重可传递给同 seed 的下游阶段，但不能复制完成的模型冒充另一独立训练。

开放的可执行方法面至少包括：

1. 实例相似度及实例软标签构造。
2. 时间对齐、时间软标签和增强策略。
3. 置信度感知的伪标签生成及再训练策略。

不能仅提交 tau、lambda 等系数。预先固定主指标、类不平衡处理、准确率或 Macro-F1 的质量门，以及阶段选择规则。公开 Dev 用于研究决策，私有集只供最终独立评价。

## 健康对照与困难依据

正式 B 为完整健康 SoftCLT 半监督链，底座方法可作额外锚点。两边使用相同标注预算、阶段资源约束和验证选择规则。不能让 B 只完成预训练而 R 完成全部微调，也不能给 R 额外真实标签。

困难预评关键项为 E4：端到端结果依赖七阶段、多个 checkpoint、固定低标注子集、DTW/软标签预处理以及伪标签反馈。官方主入口和 Trainer 对 `num_epochs`、`load_epoch` 的使用不同，必须逐阶段核实实际执行。

公开配置采用小型神经网络，适合优先尝试单卡训练；本次未测显存和完整阶段成本。正式范围使用小型公开数据，不复现全 128/30 数据集或大型 SleepEEG 预训练。

统一阶段输出、加载路径、配置和 seed；固定伪标签仅来源于训练数据。原脚本在多个阶段计算测试成绩，正式研究入口须改为 Dev 口径，并把私有标签移到独立评价端。公共改造同时用于 B/R。
